# Architecture Decision Records (ADRs)

ADRは、プロジェクトの重要な設計判断と、その背景・代替案・影響を記録します。

## Index

- [0001 — Canonical annotation model](0001-canonical-annotation-model.md)

## Status values

- **Proposed**: 提案段階。まだ採用を確定していない
- **Accepted**: 採用済み
- **Deprecated**: 現在は推奨しない
- **Superseded**: 後続ADRに置き換えられた

## Naming

NNNN-short-title.md の形式で連番を付けます。採番済みの番号は再利用しません。

## Template

新しいADRでは、必要に応じて次の項目を使います。

- Title
- Status
- Context
- Decision
- Alternatives considered
- Consequences
- Follow-up work
