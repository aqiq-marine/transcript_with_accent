# ADR 0002: VOICEVOX Project Export

- Status: Accepted
- Date: 2026-10-28

## Context

このプロジェクトでは、Geminiによる文字起こし・アクセント推定とF0解析を行い、人間が読みやアクセント句、モーラごとのH/Lを確認する。その結果を使って音声を合成したいが、最終的な編集と合成はVOICEVOXエディター上で行いたい。

VOICEVOX Engine APIはAudioQueryの作成や音声合成を行うが、テキストやAudioQueryをEngineに送信するだけで、VOICEVOXエディターのGUIに編集状態が同期されたり、`.vvproj` が作成されたりする仕組みではない。

VOICEVOXエディターは編集内容を `.vvproj` プロジェクトファイルとして保存・読み込みできる。したがって、既存のエディターで作業を続けるには、正規アノテーションからこのプロジェクトファイルを生成するのが適切である。

## Decision

1. プロジェクト独自のエンジン非依存アノテーションを正規データとして保持する。
2. 正規アノテーションをVOICEVOXエディターが読み込める `.vvproj` に変換するエクスポーターを用意する。
3. ユーザーは生成された `.vvproj` をVOICEVOXエディターで開き、読み・アクセント・イントネーションを確認または修正して、エディター上で音声合成を行う。
4. Engine APIへの送信は、必要に応じた解析・変換・検証のために利用してよいが、プロジェクトファイルの作成やGUI同期の代替とはみなさない。
5. `.vvproj` の形式はVOICEVOXエディターのバージョンに依存し得るため、生成実装は対象バージョンの公式スキーマ、読み込み処理、エディターで保存したサンプルを根拠にする。
6. H/LラベルとVOICEVOXのアクセント核・モーラpitchは同一の表現ではない。変換できない情報を正規アノテーションから消さず、必要に応じて変換上の制約として明示する。

## Alternatives considered

### Engine APIにデータを送ってプロジェクトを作成する

採用しない。標準Engine APIは合成用クエリと音声を扱うAPIであり、エディターの `.vvproj` を作成・同期するAPIではない。

### VOICEVOXエディターを使わず独自GUIで合成する

採用しない。最終的なアクセント確認・編集・合成はVOICEVOXエディターで行うという利用方針に合わない。

### VOICEVOX AudioQueryを正規データとして保存する

採用しない。AudioQueryはVOICEVOX固有であり、元音声のF0、独自H/L、推定の出典、レビュー状態などを保持する正規データとしては不十分。

## Consequences

- 生成したプロジェクトをVOICEVOXエディターで開いて、通常の編集・試聴・合成ワークフローを利用できる。
- `.vvproj` のシリアライズとバージョン互換性を扱うエクスポーターが必要になる。
- 生成ファイルの受け入れテストには、対象バージョンのVOICEVOXエディターで開く統合テストが必要になる。
- VOICEVOXが表現できないピッチ情報やアノテーションの出典は、正規データ側に保持する必要がある。

## Follow-up work

- VOICEVOXエディターの対象バージョンを決める。
- 対象バージョンで最小の `.vvproj` を保存し、公式スキーマと読み込み・マイグレーション処理を調べる。
- テキスト、読み、話者、アクセント句、モーラpitchを含む最小プロジェクトを生成して、エディターで開けることを検証する。
- 正規H/LからVOICEVOXのアクセント核・pitchへの変換規則と、表現できないケースを文書化する。
